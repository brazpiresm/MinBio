# MinBio

## Mining impacts on biodiversity

Code used for the analyses and figures presented in:

*Braz Pires et al. Mining strongly reduces local biodiversity across terrestrial and freshwater ecosystems*

Please refer to the publication for additional details. 

## Data

All data are publicly available at https://doi.org/10.6084/m9.figshare.33269208. 

The Figshare repository contains the datasets required to reproduce the analyses. After downloading the data, place the files in the `data/` directory while preserving the folder structure used in the archive.

The analysis scripts assume that the repository structure is preserved and should be run from the repository root.

## Scripts

`00_functions.R`  
Contains the functions used by the analysis scripts. These include data preparation, calculation of log response ratios and sampling variances, imputation of missing standard deviations, construction of variance-covariance matrices for effect sizes sharing controls, fitting of multilevel meta-analytic models, moderator analyses, pairwise contrasts, and publication-bias analyses.

`01_richness.R`  
Runs all analyses of species richness. 
The primary analysis uses Bracken's method to impute missing standard deviations and accounts for covariance among effect sizes sharing a control group. Alternative standard-deviation treatments and unweighted analyses can be run by changing the settings at the beginning of the script.

`02_abundance.R`  
Runs all analyses of species abundance. As for species richness, alternative standard-deviation treatments and unweighted analyses are controlled through the settings at the beginning of the script.

`03_robustness_checks.R`  
Runs additional robustness checks for the richness and abundance analyses. These analyses test the sensitivity of the main results to alternative data-processing and model assumptions. The response variable is selected using the `OUTCOME` setting at the beginning of the script. The script should therefore be run separately for species richness and abundance.

`04_abundance_RE_comparison.R`  
Compares alternative random-effects structures for the species abundance meta-analysis. This script was used to assess the influence of the hierarchical random-effects specification on the estimated abundance responses.

`05_figures.R`  
Generates the main text and SI figures. The script reads the model objects and summary tables generated by the preceding analysis scripts and reproduces the figures reported in the manuscript.
